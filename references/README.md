# Original source documents

The documents in this folder are retained unchanged for provenance.

- `ijaw_rules_reference.docx`: copy of the rule table supplied by the project owner.
- `ijaw_sentence_translation_examples.docx`: copy of the Izon sentences and their English translations supplied by the project owner.
- `pronouns_reference.docx`: uploaded pronoun reference used for pronoun and interrogative rule extraction.
- `izon_english_grammar_rules_reference.docx`: uploaded Izon–English grammar reference used for the bilingual grammar inventory.

Some source tables contain ambiguous formatting, mixed dialect coverage, or incomplete transcription. Such material is retained as a reference and should not automatically be treated as confirmed productive Kolokuma grammar.
